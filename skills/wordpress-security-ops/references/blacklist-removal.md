# Blacklist Removal

Use as a sub-flow of `recover` or `report`. Remove the cause before requesting a review.

## Order of Work

1. Confirm the site is clean.
2. Remove malware, spam and redirects.
3. Verify checksums and scans.
4. Check login, checkout and forms.
5. Request review from each service.
6. Recheck after 24-72 hours.

## Search Engines

### Google Safe Browsing

- Check the status in Search Console.
- Fix the cause.
- Request a review.
- Recheck after 24-72 hours.

### Google Search Console

- Security Issues report.
- Manual Actions report.
- Request a review with a clear explanation.
- Keep the fix evidence.

### Yandex Webmaster

- Security and virus section.
- Remove the cause.
- Request a recheck.
- Check the Yandex search snippets.

### Bing Webmaster

- Security issues.
- Request a review.
- Recheck.

## Reputation Services

| Service | Action |
|---|---|
| Microsoft SmartScreen | Submit a false-positive or fixed-site report |
| McAfee SiteAdvisor | Request a recheck |
| Norton Safe Web | Request a recheck |
| Sucuri SiteCheck | Scan and recheck |
| VirusTotal | Re-scan after the fix |
| URLVoid | Recheck after the fix |

## Host and Registrar

- Ask the host to remove a block if the site was suspended.
- Ask the registrar if the domain is on hold.
- Keep the abuse contact and ticket IDs.
- Do not change DNS before the cause is fixed.

## SEO Cleanup

- Check `site:` results.
- Check titles and snippets.
- Remove spam pages and comments.
- Update the sitemap.
- Request reindexing after the fix.
- Monitor impressions and clicks.

## Evidence

- Save screenshots and timestamps of each status.
- Save the request and response IDs.
- Record who submitted and when.
- Recheck and record the result.

## Do Not

- Request a review before removing the cause.
- Hide the problem from the client.
- Promise instant removal.
- Blame the search engine without evidence.
- Delete logs or evidence after the review.

## Stop Conditions

- The site is still infected.
- The client wants to hide a breach instead of fixing it.
- The domain is suspended and legal action is involved.
